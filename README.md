
# SEC Studios — Filmmaking Support Website

## Project Overview

SEC Studios is a website concept designed to support independent
filmmakers and small production teams. It presents filmmaking
support services, encourages creative collaboration, and provides
a contact form for project inquiries.

## Objectives

- Create a professional website for SEC Studios.
- Present filmmaking support services clearly.
- Help independent filmmakers explore production resources.
- Provide an easy-to-use contact section.
- Build a responsive website for desktop and mobile devices.

## Features

- Modern cinematic design.
- Home, About, Services, and Contact sections.
- Crew connection and production support information.
- Equipment resource information.
- Responsive navigation menu.
- Contact form with basic client-side validation.
- Automatic copyright year.

## Technologies Used

- HTML5 — website structure.
- CSS3 — styling and responsive layout.
- JavaScript — navigation and form interaction.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all project files are in the same folder.
4. Open index.html in a web browser.
5. Alternatively, use the Live Server extension in VS Code.

## Website Sections

### Home
Introduces SEC Studios and its filmmaking support concept.

### About
Explains the purpose and goals of SEC Studios.

### Services
Presents crew connections, production support,
equipment resources, and creative collaboration.

### Contact
Provides a form for visitors to enter their name,
email address, and project details.

## Important Note

This is a front-end demonstration project. The contact form
does not currently send or store submissions. A backend or
form service is required to receive real inquiries.

Services described on this website represent the proposed
SEC Studios concept and should not be interpreted as a
guarantee that all services are currently available.

## Future Improvements
